📋 Comment Jouer au Red Dog
🎮 Objectif du Jeu
Parier sur l'écart entre deux cartes. Si une troisième carte tombe dans l'écart, vous gagnez !
🃏 Comment Jouer
1. Deux cartes sont distribuées
2. Si elles sont consécutives, c'est un "push" (égalité)
3. Si elles sont identiques, double mise gagnée
4. Sinon, un écart se forme
5. Une troisième carte est tirée
6. Si elle tombe dans l'écart, vous gagnez selon les cotes
💰 Cotes de Gain
Écart de 1 : 5x la mise
Écart de 2 : 4x la mise
Écart de 3 : 3x la mise
Écart de 4-7 : 2x la mise
Cartes identiques : 11x la mise
