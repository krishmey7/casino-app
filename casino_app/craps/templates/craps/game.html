📋 Comment Jouer au Craps
🎮 Objectif du Jeu
Le craps est un jeu de dés où vous pariez sur le résultat du lancer de deux dés. Le but est de prédire si le lanceur va gagner ou perdre selon les règles complexes du jeu.
🎲 Les Lancers
• Come Out Roll : Premier lancer de la manche
• Point : Si 4,5,6,8,9,10 sort, devient le point à refaire
• Seven Out : Si 7 sort après un point, la manche se termine
💰 Types de Paris
  1. Pass Line : Pari sur le lanceur (avant le come out)
  2. Don't Pass : Pari contre le lanceur
  3. Come : Comme Pass Line mais après le point
  4. Don't Come : Comme Don't Pass mais après le point
  5. Place Bets : Sur des numéros spécifiques (4,5,6,8,9,10)
🏆 Résultats et Paiements
• Come Out 7 ou 11 : Pass Line gagne (1:1)
• Come Out 2, 3 ou 12 : Pass Line perd (Craps)
• Point établi puis refait : Pass Line gagne (1:1)
• 7 avant le point : Pass Line perd
• Place Bets : Paiements variables selon le numéro
💡 Règles Importantes
• Le 7 est le numéro le plus probable
• Les craps (2,3,12) sont défavorables au lanceur
• Une fois le point établi, on essaie de le refaire avant le 7
• La maison a toujours un léger avantage
⚠️ Conseils Importants
• Jouez de manière responsable
• Définissez un budget
• Les jeux de hasard comportent des risques
• Ne misez que ce que vous pouvez perdre
